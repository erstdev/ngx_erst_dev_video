# Workflow

Короткая версия процесса. Полные детали — в `AGENTS.md`, `docs/conventions.md`
и `docs/roadmap.md`.

## Новый чат

1. Открой `CONTEXT.md` — это короткая точка входа, а не энциклопедия.
2. Возьми шаблон из `docs/task-template.md` и заполни карточку задачи.
3. Вставь в чат только:
   - разделы `CONTEXT.md` «Сейчас» и «Решения»;
   - карточку задачи;
   - список файлов «Прочитать» и «Не читать».
4. Не копируй весь `CONTEXT.md` и не перечисляй все компоненты.

## Один кирпич — один чат

- Новый компонент/директива/сервис — отдельный чат.
- Внутри чата читаются только целевые файлы и один эталонный соседний кирпич.
- Для независимых кирпичей можно запускать subagents с узким scope; в основной
  чат возвращается только результат и список файлов.

## Во время работы

- Сначала `grep`/`glob`, потом `read` нужного фрагмента.
- Большие файлы — через `offset`/`limit`.
- Не читать `node_modules`, `dist`, `.nx`, lock-файлы и старые спринты.
- Соблюдать `docs/conventions.md`: Angular 22, signals, OnPush, `input()`/`output()`,
  `customClass` на хост, CSS-переменные с дефолтами в `:host`, README на русском.

## Завершение задачи

1. `npx prettier --write` по изменённым файлам.
2. `npx nx lint <project>` и `npx nx build <project>` для затронутых проектов.
3. Для UI — браузерная проверка демо-страницы.
4. Обновить:
   - `CONTEXT.md` — текущий статус, решения, следующий шаг;
   - `docs/journal.md` — одна-две строки;
   - `docs/roadmap.md` / `docs/architecture.md` / `docs/conventions.md` — только
     если менялись структура, API или правила;
   - README пакета и README кирпича.
5. Закоммитить и запушить после зелёных проверок.
   `CONTEXT.md` в `.gitignore`, `docs/` версионируется.

## Breaking changes

Публичный контракт — селекторы, входы/выходы, CSS-переменные, типы и API
`VideoService`. Ломающие изменения — только в мажорной версии. Подробности:
`docs/conventions.md`, раздел «Что нельзя ломать».

## Когда закрывать чат

- закончился один кирпич;
- чат длиннее 30–40 сообщений с кодом;
- ассистент начал путаться или читать лишнее;
- переключились на другой пакет или спринт.
