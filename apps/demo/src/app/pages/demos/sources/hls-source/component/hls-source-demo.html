Директива не управляет интерфейсом: селект, статус и обработку ошибок рисует демо. autoplay применяется при следующем разборе манифеста — переключите «Поток» выкл/вкл, чтобы применить его к уже загруженному потоку. enabled = false уничтожает hls.js, убирает src и вызывает video.load(). Без MSE (iOS Safari) директива не грузит hls.js, а выставляет video.src — уровней в этом режиме нет. На <video> имя выхода error совпадает с нативным событием, поэтому демо отбрасывает события без code и message.

Что делает директива

Что Значение в демо Поведение
[ngxHlsSource] test-streams.mux.dev/x36xhzz/x36xhzz.m3u8 URL манифеста строкой; null и пустая строка выгружают поток
[autoplay] выключен, переключатель запускает video.play() после MANIFEST_PARSED
[enabled] включено, переключатель false уничтожает hls.js и очищает источник
[level] Auto или id уровня null — auto (currentLevel = -1), неизвестный id игнорируется
(levelsChange) {{ levels().length }} уровней доступные уровни после разбора манифеста, без «auto»
(levelChange) {{ currentLevelLabel() }} фактический уровень на LEVEL_SWITCHED; null — auto
(error) {{ error() ? error()?.code : 'нет' }} фатальные ошибки hls.js, неподдерживаемый браузер, блокировка autoplay

Базовая разметка

Директива вешается на <video> и работает вместе с ngxVideo, но не требует его. Манифест грузит hls.js; fetch и HttpClient не используются.

Уровни и выбор качества

levelsChange приносит уровни без «auto», а levelChange сообщает фактический уровень. Значение селекта — id уровня; «Auto» — это null.

Ошибки, autoplay и SSR

Фатальные ошибки приходят в error с кодом network, decode, source-not-supported, playback-blocked или unknown. Автоматического recover нет. На <video> этот же обработчик получает нативное событие error, поэтому VideoError отличают по полям code и message. На сервере директива не трогает DOM и не импортирует hls.js.
