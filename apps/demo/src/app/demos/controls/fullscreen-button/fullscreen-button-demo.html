Состояние приходит из VideoService, а запрос выполняет video.toggleFullscreen() в обработчике родителя. Под каждым примером — блок «Код примера».

Базовый: кнопка на плеере

{{ video.fullscreen() ? 'полноэкранный режим' : 'обычный режим — клик по кнопке развернёт видео' }}

Кнопка только эмитит toggle: вызов requestFullscreen() и выход из режима — задача VideoService. В полноэкранном режиме виден сам <video>, поэтому выйти можно клавишей Esc.

Свои размер и цвета

fullscreen: {{ video.fullscreen() ? 'да' : 'нет' }}

Класс из customClass вешается на хост-элемент, поэтому переменные задаются обычными стилями — без ::ng-deep.

Своя иконка через ng-template

fullscreen: {{ video.fullscreen() ? 'да' : 'нет' }}

В шаблон передаётся контекст FullscreenButtonIconContext с полем fullscreen.

{{ fullscreen ? '⤡' : '⤢' }}
