Время обновляется сигналами VideoService: клик по видео запускает воспроизведение. Под каждым примером — блок «Код примера».

Базовый: видео и время через VideoService

{{ video.isPlaying() ? 'идёт воспроизведение' : 'клик по видео — play/pause' }}

Компонент только форматирует переданные числа. Подписку на video.time() и video.duration() держит шаблон родителя, поэтому компонент не знает о сервисе.

Свои цвет и размер

Класс из customClass вешается на хост-элемент, поэтому переменные задаются обычными стилями — без ::ng-deep.

Длинное видео: формат с часами

Значения больше часа formatTime выводит как ч:мм:сс: 1:02:05 / 2:02:05. До часа формат остаётся мм:сс.
