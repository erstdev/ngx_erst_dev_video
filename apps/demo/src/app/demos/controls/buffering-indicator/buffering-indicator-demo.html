Индикатор ничего не решает сам: состояние приходит через вход state. Под каждым примером — блок «Код примера».

Базовый: индикатор поверх видео

Индикатор виден только при state === 'buffering'. Момент включения определяет VideoService, поэтому на быстром видео спиннер может не успеть появиться. Ниже состояние можно переключить вручную.

Состояние задаёт родитель

delay 0 — сразу
delay 300 мс
state: {{ demoState() }}

При задержке 300 мс индикатор появится, только если буферизация длится дольше: короткие провалы не мигают. По умолчанию delay равен 0 — показывать сразу.
