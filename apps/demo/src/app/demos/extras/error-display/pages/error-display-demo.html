Ошибка симулируется сигналом, реальный сетевой сбой не нужен. Нажмите «Показать ошибку», чтобы увидеть карточку; «Повторить» скрывает её и запускает видео. Переключатель включает customClass с переменными --ngx-error-*.

state: {{ video.state() }}

Пока demoError равен null, карточки нет в DOM. Клик по «Повторить» только эмитит retry: сигнал очищается и video.play() вызывает родитель.

Базовая разметка

Контейнер плеера — position: relative, карточка растянута по нему через position: absolute; inset: 0. Ошибка приходит снаружи, чаще всего из video.error().

Обработка retry

Компонент не знает, как исправлять ошибку. Родитель очищает своё состояние и решает, что запускать дальше.

customClass и CSS-переменные

Класс вешается на хост-элемент, поэтому переменные переопределяются обычными scoped-стилями — без ::ng-deep.
