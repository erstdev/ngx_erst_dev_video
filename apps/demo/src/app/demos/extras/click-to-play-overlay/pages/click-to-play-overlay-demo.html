Оверлей существует только в состояниях idle и paused. Нажмите на него, чтобы запустить видео, и на видео — чтобы поставить паузу. Переключатели ниже включают свою иконку и customClass на том же плеере.

state: {{ video.state() }}

Чтобы увидеть изменения, поставьте видео на паузу — при playing, buffering, seeking, ended и error кнопки оверлея нет в DOM.

Базовая разметка

Контейнер плеера — position: relative, оверлей растянут по нему через position: absolute; inset: 0. Клик по оверлею только эмитит play; запуск выполняет родитель.

Своя иконка через iconTemplate

Шаблон заменяет только иконку и получает контекст { state }. Размер контейнера задаёт переменная --ngx-overlay-icon-size.

customClass и CSS-переменные

Класс вешается на хост-элемент, поэтому переменные переопределяются обычными scoped-стилями — без ::ng-deep.
