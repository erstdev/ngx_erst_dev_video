При загрузке страницы запись не начинается и скачиваний нет — только по клику. Выберите лимит, нажмите «Начать запись» и проверьте таймер: по достижении maxDuration компонент остановится сам. «Остановить» доступна, пока идёт запись, даже если включён disabled; после стопа или ошибки старт снова доступен. Видео зациклено, чтобы запись не обрывалась на конце короткого ролика. Предпросмотр и ручная ссылка ниже используют один и тот же Blob: object URL создаёт демо и освобождает его в DestroyRef.

Что делает компонент

Что Как
Входы video, maxDuration, mimeType, videoBitsPerSecond, audioBitsPerSecond, timeslice, disabled, customClass, ariaLabel, indicatorTemplate
Выходы recordStart (запись началась), recordStop (Blob с фактическим MIME), recordError (CaptureError)
Старт и стоп CaptureService.recordClip(video, options); пока идёт запись, старт disabled, повторные клики игнорируются. «Остановить» вызывает ClipRecording.stop() и доступна даже при disabled = true
Таймер и лимит 00:00 в ожидании, обновление каждые 250 мс, после стопа — фактическая длительность. По maxDuration авто-стоп; лимит фиксируется на момент старта, 0 — без ограничения
Ошибки recordError с CaptureError; чужое исключение → recording-failed с cause; состояние error обрабатывается без ожидания клика, исключение наружу не пробрасывается
Плеер и файлы Не управляет: play(), pause(), seek() и VideoService — не его зона; не скачивает файлы и не хранит историю — скачивание делает демо
SSR Нет window, document и MediaRecorder на верхнем уровне; setInterval создаётся только в обработчике клика

Базовое использование

Компонент получает нативный элемент через viewChild, сам вызывает CaptureService.recordClip() по клику и отдаёт готовый Blob в recordStop. Плеером управляет VideoService — компонент лишь передаёт текущее состояние видео в сервис захвата.

maxDuration и таймер

maxDuration задаёт лимит в секундах: по его достижении компонент останавливает запись сам, а recordStop приходит один раз. Лимит фиксируется на момент старта; 0 отключает ограничение.

Ошибки и SSR

Ошибки приходят в recordError обычным CaptureError; чужое исключение оборачивается в recording-failed. На сервере компонент рендерится без DOM: setInterval появляется только в обработчике клика.
