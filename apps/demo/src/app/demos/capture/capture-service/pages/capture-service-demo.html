Сервис получает нативный HTMLVideoElement и возвращает Blob или объект записи. Воспроизведением управляет VideoService: кнопка Play/Pause вызывает toggle(), а CaptureService только снимает кадры с текущего состояния. Файлы не скачиваются автоматически — ссылки «Скачать» появляются после захвата, и скачивание инициирует демо.

Кадр и GIF снимаются через Canvas: без CORS-заголовков у видео canvas становится «грязным» и отдаёт ошибку canvas-failed, поэтому у элемента стоит crossorigin="anonymous". Запись идёт через MediaRecorder из video.captureStream(); если видео на паузе, кадры в клипе могут повторяться — это ответственность родителя. GIF — настоящий image/gif с палитрой 3-3-2 и задержкой max(2, round(100 / fps)) сотых секунды: 2 секунды при 10 к/с. На сервере методы отклоняются с кодом unsupported.

Что делает сервис

Метод Опции Поведение
captureFrame(video, options) type (PNG), quality (0.92), maxWidth, maxHeight Canvas → Blob; пропорции сохраняются, кадр не увеличивается; без кадра — no-video; элемент не меняется
recordClip(video, options) mimeType, videoBitsPerSecond, audioBitsPerSecond, timeslice MediaRecorder из captureStream(); возвращает ClipRecording со state, stop() и cancel(); API проверяется синхронно
captureGif(video, options) fps (10), duration (3000), width (320), loop (true) Собственный GIF89a: палитра 3-3-2, LZW и Netscape loop; кадры снимаются 2–15 секунд
Ошибки code, message, cause Обычный объект CaptureError, как VideoError в core; code — контракт, текст русский
SSR и CORS — На сервере — unsupported; без CORS-заголовков canvas «грязный» и отдаёт canvas-failed
Границы — Без UI и селектора, без VideoService, без auto-download и без хранения результатов

Кадр

captureFrame получает нативный элемент и возвращает Blob. Кадр снимается с текущего состояния: сервис не вызывает play(), pause() и seek(), а скачивание остаётся за демо.

Запись клипа

recordClip сразу начинает запись и возвращает ClipRecording. stop() идемпотентен и отдаёт Blob с фактическим MIME, cancel() выбрасывает данные и отклоняет ожидающий stop() с кодом aborted.

GIF

captureGif снимает кадры с заданным fps в течение duration и кодирует настоящий GIF89a без зависимостей: глобальная палитра 256 цветов 3-3-2, LZW и Netscape loop.
