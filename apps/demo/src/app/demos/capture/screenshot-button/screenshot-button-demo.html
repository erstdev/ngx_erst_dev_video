Захват выполняет CaptureService: кнопка передаёт ему нативный HTMLVideoElement и настройки кадра, а получает готовый Blob. Воспроизведением управляет VideoService — кнопка не вызывает play(), pause() и seek(). При загрузке страницы скачиваний нет — только по клику по кнопке камеры. Предпросмотр и ручная ссылка используют один и тот же Blob: object URL создаётся в демо и освобождается в DestroyRef. Кнопка блокируется на время захвата (aria-busy="true"), а после ошибки снова активна. Без CORS-заголовков у видео Canvas становится «грязным» и отдаёт canvas-failed, поэтому у элемента стоит crossorigin="anonymous".

Базовое использование

Компонент получает нативный элемент через viewChild, сам вызывает CaptureService по клику и по умолчанию скачивает готовый Blob. Плеером управляет VideoService — кнопка лишь передаёт текущее состояние видео в сервис захвата.

Опции, имя файла и скачивание

type, quality и лимиты размеров уходят в captureFrame(). Расширение файла компонент добавляет сам по MIME; при download = false он ничего не скачивает и оставляет Blob потребителю.

Ошибки и SSR

Ошибки приходят в captureError обычным CaptureError; чужое исключение оборачивается в canvas-failed. На сервере компонент рендерится без DOM: document появляется только в обработчике клика.

Стилизация через customClass

customClass вешает классы на хост <ngx-screenshot-button>, поэтому обычные scoped-стили потребителя переопределяют --ngx-screenshot-* и задают собственные хост-стили вроде box-shadow. Классы из class="..." при этом сохраняются.
