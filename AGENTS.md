# AGENTS.md

Правила для ассистента в этом репозитории. Главная цель — не раздувать контекст
и не читать лишние файлы.

## Что читать

- `CONTEXT.md` — короткая точка входа: текущий спринт, решения, следующий шаг.
- Только файлы из списка «Прочитать» в карточке задачи.
- Один соседний кирпич как эталон — если он явно указан.
- `docs/` — только по ссылке из задачи и только нужный файл:
  - `docs/architecture.md` — структура и ответственность кирпичей;
  - `docs/conventions.md` — код, стили, breaking changes;
  - `docs/roadmap.md` — план работ по пунктам: задачи, статусы, справочник;
  - `docs/journal.md` — история;
  - `docs/workflow.md` — процесс;
  - `docs/references.md` — ссылки и авторство.

## Что не читать

- Все компоненты и README пакетов подряд.
- `node_modules`, `dist`, `.nx`, lock-файлы, сгенерированные артефакты.
- Историю чата и старые спринты, если задача не про них.
- Полный `CONTEXT.md` прошлых версий — используй короткую версию.

## Как искать

- Сначала `glob`/`grep` по символу или селектору, потом `read` нужного фрагмента.
- Большие файлы читай через `offset`/`limit`.
- После правки не перечитывай файл целиком без необходимости.
- Не пересказывай содержимое файлов в ответе — ссылайся на пути и строки.

## Как работать

- Новый чат — один кирпич, а не весь спринт.
- В начале чата используй карточку задачи из `docs/task-template.md`.
- Для независимых компонентов — отдельные subagents с узким scope.
- Соблюдай `docs/conventions.md`: Angular 22, signals, OnPush, `input()`/`output()`,
  `customClass` на хост, CSS-переменные с дефолтами в `:host`, README на русском.
- Не добавляй зависимости и тесты без согласования.
- Не меняй публичный API `core` без отдельного решения.
- `CONTEXT.md` в `.gitignore`; документация в `docs/` версионируется.

## Проверки

- `npx prettier --write` по изменённым файлам.
- `npx nx lint <project>` и `npx nx build <project>` для затронутых проектов.
- Демо-страницы проверять в браузере, если менялся UI.
- Коммит и push — после зелёных проверок.

## Формат ответа

- Сначала — что изменено и где смотреть.
- Список файлов, проверки, остаток работы.
- Без длинных листингов кода, если их не просили.
