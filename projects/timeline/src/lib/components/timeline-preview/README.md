# TimelinePreviewComponent

Превью кадра для таймлайна: показывает, что находится в выбранной точке, не
перематывая основной плеер.

Селектор: `ngx-timeline-preview`.

## Назначение и границы ответственности

**Делает:**

- принимает время и источник видео;
- лениво создаёт отдельный скрытый `<video>`;
- перематывает только его и рисует кадр в `<canvas>`;
- показывает время и заглушку, пока кадр не готов;
- полностью отключается входом `enabled`.

**Не делает:**

- не трогает основной `<video>` и его `currentTime`;
- не управляет воспроизведением;
- не вызывает `video.seek()` и не знает о `VideoService`;
- не является интерактивным элементом: превью декоративное.

## Импорт

```ts
import { TimelinePreviewComponent } from '@erst_dev/ngx-video-timeline';
```

## Использование

`TimelinePreviewComponent` обычно передаётся в `previewTemplate` таймлайна:

```html
<ngx-timeline [currentTime]="video.time()" [duration]="video.duration()" [previewTemplate]="preview" (seek)="video.seek($event)" />

<ng-template #preview let-time="time">
  <ngx-timeline-preview [time]="time" [src]="src" />
</ng-template>
```

Таймлайн считает время под курсором и позиционирует контейнер; превью только
рисует кадр.

## Входы

| Вход          | Тип              | По умолчанию | Описание                                                                      |
| ------------- | ---------------- | ------------ | ----------------------------------------------------------------------------- |
| `time`        | `number`         | — (required) | Время кадра в секундах                                                        |
| `src`         | `string`         | — (required) | Источник видео; обычно тот же `src`, что у основного плеера                   |
| `enabled`     | `boolean`        | `true`       | При `false` компонент не рендерится, скрытое видео не создаётся и не грузится |
| `previewSrc`  | `string \| null` | `null`       | Необязательный лёгкий источник для превью; если не задан, используется `src`  |
| `customClass` | `string`         | `''`         | Дополнительный CSS-класс для хост-элемента `<ngx-timeline-preview>`           |

## Выходы

Выходов нет: компонент только отображает кадр.

## Как получается кадр

1. При первом запросе создаётся отдельный скрытый `<video>` с `muted`,
   `playsInline`, `preload="auto"` и нужным `src`.
2. Компонент выставляет `currentTime` и ждёт `seeked`.
3. Кадр рисуется в canvas через `drawImage` с сохранением пропорций.
4. Пока кадр не готов, показывается заглушка со временем.

Ключевые детали реализации:

- скрытое видео создаётся лениво и удаляется при уничтожении компонента;
- запросы seek не запускаются параллельно: новый hover заменяет ожидающий;
- повторный seek в близкую точку (меньше 0.2 с) пропускается;
- при `enabled = false` видео останавливается, `src` очищается и элемент
  удаляется — нагрузка пропадает полностью;
- при смене `src`/`previewSrc` старое видео освобождается и создаётся новое;
- если кадр получить не удалось, остаётся заглушка со временем.

## CORS и ограничения

Canvas используется только для **показа**. Если видео загружено с другого
источника без CORS, canvas может стать «загрязнённым»: показывать его можно, но
`toDataURL()`/`getImageData()` будут недоступны. Для превью это не нужно.

`crossorigin` компонент по умолчанию не ставит: если сервер не отдаёт
`Access-Control-Allow-Origin`, видео с этим атрибутом может вообще не загрузиться.
Для кэширования кадров как data URL понадобится CORS и отдельная настройка.

Ограничения Спринта 3:

- обычное прогрессивное видео (`MP4`/`WebM`);
- HLS/DASH требуют интеграции с пакетом `sources`;
- на некоторых мобильных браузерах второй видеоэлемент декодируется ограниченно;
- DRM/защищённые источники могут не отдавать кадр в canvas — останется заглушка.

| Переменная                           | По умолчанию                     | Описание                       |
| ------------------------------------ | -------------------------------- | ------------------------------ |
| `--ngx-timeline-preview-width`       | `160px`                          | Ширина превью                  |
| `--ngx-timeline-preview-bg`          | `#000000`                        | Фон рамки кадра                |
| `--ngx-timeline-preview-color`       | `#ffffff`                        | Цвет текста                    |
| `--ngx-timeline-preview-muted-color` | `rgba(255, 255, 255, 0.7)`       | Цвет заглушки                  |
| `--ngx-timeline-preview-radius`      | `0.375rem`                       | Скругление рамки               |

| `--ngx-timeline-preview-font-size`   | `0.75rem`                        | Размер подписи со временем     |
| `--ngx-timeline-preview-gap`         | `0.25rem`                        | Отступ между кадром и временем |

## Стилизация

```scss
ngx-timeline-preview {
  --ngx-timeline-preview-width: 200px;
  --ngx-timeline-preview-radius: 0.5rem;
  --ngx-timeline-preview-shadow: 0 12px 32px rgba(0, 0, 0, 0.5);
}
```

Через `customClass` — класс вешается на **хост-элемент** `<ngx-timeline-preview>`:

```html
<ngx-timeline-preview customClass="my-preview" [time]="time" [src]="src" />
```

```scss
/* player.component.scss — обычные scoped-стили, без ::ng-deep */
.my-preview {
  --ngx-timeline-preview-width: 200px;
  --ngx-timeline-preview-radius: 0.5rem;
}
```

## Отключение

```html
<ngx-timeline-preview [time]="time" [src]="src" [enabled]="previewEnabled()" />
```

При `enabled = false` компонент не создаёт скрытое видео и не делает seek.
Это не просто `display: none` — нагрузка действительно исчезает.

## Доступность

- Корневой блок помечен `aria-hidden="true"`: это декоративное превью.
- Компонент неинтерактивен и не попадает в порядок табуляции.
- Время доступно скринридеру через `aria-valuetext` таймлайна, дублировать его
  в превью не нужно.

## SSR

Скрытое видео и canvas создаются только в браузере (`isPlatformBrowser`).
На сервере рендерится пустой/временной блок без DOM API. `customClass`
синхронизируется через `ElementRef`, как в остальных кирпичах.
