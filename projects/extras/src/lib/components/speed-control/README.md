# SpeedControlComponent

Селектор скорости воспроизведения: показывает текущее значение и сообщает о
выборе нового. Скорость к видео не применяет — это делает родитель, обычно через
`VideoService.setPlaybackRate()`.

Селектор: `ngx-speed-control`.

## Назначение и границы ответственности

**Делает:**

- показывает текущую скорость в нативном `<select>`;
- строит список опций из `rates` в заданном порядке, без дублей;
- добавляет текущую скорость в конец списка, если её нет среди `rates`;
- сообщает о выборе выхода `rateChange` только конечным положительным числом;
- поддерживает `customClass` и CSS-переменные `--ngx-speed-*`.

**Не делает:**

- не хранит состояние и не запоминает выбранное значение;
- не вызывает `setPlaybackRate()`, `play()`, `pause()` и другие методы
  медиа-элемента;
- не знает о `VideoService` и не читает состояние плеера;
- не меняет переданные `playbackRate` и `rates`;
- не переводит подписи и не управляет i18n.

## Импорт

```ts
import { SpeedControlComponent } from '@erst_dev/ngx-video-extras';
```

## Использование

```html
<div class="player">
  <video ngxVideo [src]="src" playsinline></video>

  <ngx-speed-control [playbackRate]="video.playbackRate()" (rateChange)="onRateChange($event)" />
</div>
```

```ts
import { Component, inject } from '@angular/core';
import { VideoDirective, VideoService } from '@erst_dev/ngx-video-core';
import { SpeedControlComponent } from '@erst_dev/ngx-video-extras';

@Component({
  selector: 'app-player',
  imports: [VideoDirective, SpeedControlComponent],
  templateUrl: './player.component.html',
})
export class PlayerComponent {
  readonly video = inject(VideoService);
  readonly src = 'https://example.com/video.mp4';

  protected onRateChange(rate: number): void {
    this.video.setPlaybackRate(rate);
  }
}
```

Компонент только эмитит выбранное значение. Применение скорости, проверка
поддержки браузером и синхронизация с сервисом — ответственность родителя.

## Входы

| Вход           | Тип                 | По умолчанию       | Описание                                   |
| -------------- | ------------------- | ------------------ | ------------------------------------------ |
| `playbackRate` | `number`            | — (required)       | Текущая скорость воспроизведения           |
| `rates`        | `readonly number[]` | `[0.5, 1, 1.5, 2]` | Доступные скорости в порядке показа        |
| `customClass`  | `string`            | `''`               | Дополнительный CSS-класс для хост-элемента |

## Выходы

| Выход        | Тип      | Описание                                  |
| ------------ | -------- | ----------------------------------------- |
| `rateChange` | `number` | Выбранная скорость. Применяет её родитель |

## Поведение

- Опции строятся из `rates` в том порядке, в котором они переданы. Дубликаты
  схлопываются: повторная скорость не создаёт вторую опцию.
- Некорректные значения в `rates` (не конечные числа или значения не больше
  нуля) отбрасываются — их нельзя ни показать осмысленно, ни применить.
- Если `playbackRate` отсутствует в `rates`, он добавляется в конец списка.
  Поэтому селект никогда не показывает пустое значение из-за текущей скорости,
  которой нет среди доступных.
- Подписи опций — `0.5x`, `1x`, `1.5x`, `2x`: число и суффикс `x`.
- Значение читается на нативное событие `change`, приводится через `Number` и
  эмитится только если оно конечное и больше нуля. Некорректное значение молча
  игнорируется.
- Компонент не хранит выбранное значение: отображаемая скорость определяется
  входом `playbackRate`. Если родитель не применил эмитированное значение,
  селект останется под управлением входного сигнала.

## Список скоростей

`rates` позволяет задать собственный набор. Например, для замедленного просмотра
и ускорения:

```ts
readonly rates = [0.25, 1, 3] as const;
```

```html
<ngx-speed-control [playbackRate]="video.playbackRate()" [rates]="rates" (rateChange)="onRateChange($event)" />
```

Если текущая скорость равна `1.5`, а в `rates` её нет, селект покажет
`0.25x`, `1x`, `3x`, `1.5x` — добавленную в конец текущую скорость.

## CSS-переменные

Все значения заданы в `:host`, поэтому компонент работает из коробки и
переопределяется без правки исходников.

| Переменная                  | По умолчанию               | Описание                             |
| --------------------------- | -------------------------- | ------------------------------------ |
| `--ngx-speed-bg`            | `rgba(0, 0, 0, 0.6)`       | Фон селекта                          |
| `--ngx-speed-color`         | `#ffffff`                  | Цвет текста и рамки при наведении    |
| `--ngx-speed-border-color`  | `rgba(255, 255, 255, 0.3)` | Цвет рамки в покое                   |
| `--ngx-speed-border-radius` | `0.375rem`                 | Скругление селекта                   |
| `--ngx-speed-padding`       | `0.25rem 0.5rem`           | Внутренние отступы селекта           |
| `--ngx-speed-font-size`     | `0.8125rem`                | Размер шрифта                        |
| `--ngx-speed-focus-color`   | `#60a5fa`                  | Цвет outline при фокусе с клавиатуры |
| `--ngx-speed-transition`    | `0.15s ease`               | Переход рамки и фона                 |

## Стилизация

Переопределение на самом компоненте:

```scss
ngx-speed-control {
  --ngx-speed-bg: #111827;
  --ngx-speed-border-radius: 999px;
  --ngx-speed-focus-color: #34d399;
}
```

Через `customClass` — класс вешается на **хост-элемент**
`<ngx-speed-control>`:

```html
<ngx-speed-control customClass="my-speed" [playbackRate]="video.playbackRate()" [rates]="rates" (rateChange)="onRateChange($event)" />
```

```scss
/* player.component.scss — обычные scoped-стили, без ::ng-deep */
.my-speed {
  --ngx-speed-bg: #064e3b;
  --ngx-speed-color: #d1fae5;
  --ngx-speed-border-color: #059669;
  --ngx-speed-border-radius: 999px;
  --ngx-speed-padding: 0.375rem 0.75rem;
  --ngx-speed-font-size: 0.875rem;
  --ngx-speed-focus-color: #34d399;
}
```

`customClass` не затрагивает классы, заданные на элементе вручную:
`<ngx-speed-control class="layout-wide" customClass="my-speed">` сохранит оба
класса.

## i18n

Отдельного i18n-слоя нет — это решение Спринта 4:

- подписи опций (`0.5x`, `1x`, …) состоят из числа и технического суффикса `x`,
  переводить их не нужно;
- `aria-label` селекта — фиксированный русский текст «Скорость
  воспроизведения»;
- если приложению нужен другой язык, подпись можно будет вынести в аддитивный
  вход `ariaLabel` в следующей версии, не ломая текущий API.

Компонент не переводит текст и не подменяет подписи по локали.

## Доступность

- Используется нативный `<select>`: клавиатура, поиск по первой букве, фокус и
  семантика работают без дополнительного кода.
- У селекта постоянный `aria-label="Скорость воспроизведения"` — подпись не
  теряется, если рядом нет визуального `<label>`.
- Видимый `:focus-visible` outline с настраиваемым цветом
  `--ngx-speed-focus-color`.
- При `prefers-reduced-motion: reduce` переход рамки и фона отключается.
- В селекте всегда есть выбранная опция: текущая скорость добавляется в список,
  даже если её нет среди `rates`.

## SSR

Компонент не использует `window`, `document` и медиа-API. Единственное
обращение к DOM — синхронизация классов хоста через `ElementRef` в `effect()`;
на сервере Angular предоставляет элемент так же, как в браузере. Разметка
`<select>` безопасно рендерится на сервере; событие `change` возникает только в
браузере.
