# GestureDirective

Свайпы для плеера: влево и вправо — перемотка, вверх и вниз — громкость или
яркость. Директива переводит жест в один выход и не содержит логики
воспроизведения — смещения применяет родитель, обычно через `VideoService`.

Селектор: `[ngxGesture]`.

## Назначение и границы ответственности

**Делает:**

- слушает Pointer Events на хост-элементе: `pointerdown`, `pointermove`,
  `pointerup`, `pointercancel`, `lostpointercapture`;
- ждёт, пока смещение превысит `threshold`, и фиксирует ось жеста;
- захватывает указатель через `setPointerCapture()`, чтобы жест не терялся при
  выходе курсора за пределы хоста;
- на `pointerup` считает одно смещение и эмитит `seek`, `volumeChange` или
  `brightnessChange`;
- ограничивает смещение шагом и округляет его до сотых;
- игнорирует жест на интерактивных элементах и при выключенном `enabled`.

**Не делает:**

- не хранит состояние плеера и не запоминает позицию, громкость или яркость;
- не вызывает `play()`, `pause()`, `seek()`, `setVolume()`, `setPlaybackRate()`
  и другие методы медиа-элемента;
- не знает о `VideoService`;
- не рендерит DOM, не содержит стилей и CSS-переменных;
- не управляет фокусом, не добавляет `tabindex`, `role` и ARIA-атрибуты;
- не выставляет `touch-action`: это делает потребитель;
- не эмитит выходы во время `pointermove` и не поддерживает live-режим
  (непрерывную перемотку или громкость).

## Импорт

```ts
import { GestureDirective } from '@erst_dev/ngx-video-extras';
```

## Использование

```html
<div class="player" ngxGesture [enabled]="gesturesEnabled()" (seek)="onSeek($event)" (volumeChange)="onVolumeChange($event)" (brightnessChange)="onBrightnessChange($event)">
  <video ngxVideo [src]="src" playsinline></video>
</div>
```

```scss
.player {
  /* Для touch: без этого браузер заберёт вертикальный жест под скролл. */
  touch-action: none;
}
```

```ts
import { Component, inject, signal } from '@angular/core';
import { VideoDirective, VideoService } from '@erst_dev/ngx-video-core';
import { GestureDirective } from '@erst_dev/ngx-video-extras';

@Component({
  selector: 'app-player',
  imports: [VideoDirective, GestureDirective],
  templateUrl: './player.component.html',
})
export class PlayerComponent {
  readonly video = inject(VideoService);
  readonly src = 'https://example.com/video.mp4';
  readonly gesturesEnabled = signal(true);
  readonly brightness = signal(1);

  protected onSeek(delta: number): void {
    this.video.seekBy(delta);
  }

  protected onVolumeChange(delta: number): void {
    this.video.setVolume(this.video.volume() + delta);
  }

  protected onBrightnessChange(delta: number): void {
    const next = Math.min(1, Math.max(0.2, this.brightness() + delta));
    this.brightness.set(next);
  }
}
```

Директива не применяет смещения сама: перемотку, громкость и яркость
обрабатывает родитель. `VideoService.setVolume()` сам ограничивает громкость
диапазоном `0…1`, поэтому в обработчике достаточно сложить текущее значение с
делтой.

## Входы

| Вход             | Тип       | По умолчанию | Описание                                            |
| ---------------- | --------- | ------------ | --------------------------------------------------- |
| `enabled`        | `boolean` | `true`       | Выключает обработку жестов                          |
| `seekStep`       | `number`  | `30`         | Секунды на полную ширину хоста                      |
| `volumeStep`     | `number`  | `0.5`        | Громкость на полную высоту правой половины хоста    |
| `brightnessStep` | `number`  | `0.5`        | Яркость на полную высоту левой половины хоста       |
| `threshold`      | `number`  | `12`         | Минимальная длина свайпа в пикселях до фиксации оси |

Некорректные `seekStep`, `volumeStep` и `brightnessStep` (не конечные или
`<= 0`) заменяются значениями по умолчанию. Отрицательный или нечисловой
`threshold` заменяется нулём.

## Выходы

| Выход              | Тип      | Когда эмитится                                                      |
| ------------------ | -------- | ------------------------------------------------------------------- |
| `seek`             | `number` | Горизонтальный свайп: смещение в секундах, со знаком                |
| `volumeChange`     | `number` | Вертикальный свайп в правой половине: смещение громкости, со знаком |
| `brightnessChange` | `number` | Вертикальный свайп в левой половине: смещение яркости, со знаком    |

Выходы не эмитятся, если итоговый delta после округления равен нулю.

## Жесты

| Жест                                  | Выход              | Формула                                      |
| ------------------------------------- | ------------------ | -------------------------------------------- |
| Влево / вправо                        | `seek`             | `dx / width * seekStep`, clamp в `±seekStep` |
| Вверх / вниз, старт в левой половине  | `brightnessChange` | `-dy / height * brightnessStep`, clamp       |
| Вверх / вниз, старт в правой половине | `volumeChange`     | `-dy / height * volumeStep`, clamp           |

Свайп вверх даёт положительное смещение, вниз — отрицательное. Сторона
определяется по точке `pointerdown`: левая половина — яркость, правая —
громкость. Длина свайпа нормируется на размер хоста, поэтому жест на половину
ширины даёт половину шага.

## Поведение

- **`pointerdown`.** Событие игнорируется, если `enabled = false`, указатель не
  primary, это мышь с `button !== 0`, цель — интерактивный элемент (`input`,
  `textarea`, `select`, `button`, `a`, `contenteditable`) или жест уже
  отслеживается. Иначе директива запоминает `pointerId`, стартовые координаты,
  размеры хоста и сторону старта, затем вызывает `setPointerCapture()`.
- **Порог и ось.** Пока евклидова длина смещения не превысила `threshold`,
  ось не фиксируется. Затем выбирается ось с большим абсолютным смещением; при
  равенстве — горизонталь. В момент фиксации вызывается `preventDefault()`.
- **`pointermove`.** После фиксации запоминается последнее смещение. Чужой
  `pointerId` игнорируется. Если `enabled` выключили посреди жеста, состояние
  сбрасывается без выхода.
- **`pointerup`.** Если ось зафиксирована, считается один итоговый delta:
  горизонталь — `dx / width * seekStep`, вертикаль — `-dy / height * step`.
  Результат ограничивается `±step`, округляется до сотых и эмитится только
  ненулевым.
- **`pointercancel` и `lostpointercapture`.** Сбрасывают состояние без эмита.
- **Pointer capture.** Если браузер не поддерживает `setPointerCapture()` или
  вызов не удался, жест продолжается без захвата: `pointermove` и `pointerup`
  всё равно приходят на хост, пока указатель над ним.
- **Один жест — один выход.** Во время `pointermove` выходы не эмитятся.
  Live-режим (непрерывная перемотка или громкость) в этот кирпич не входит.
- **Состояние не хранится.** Директива не читает текущее время, громкость или
  яркость: она отдаёт только смещение, а родитель решает, как его применить и
  как обрабатывать границы.
- **Мышь, pen и touch.** Используются Pointer Events, поэтому демо и жест
  работают на десктопе. Touch Events не используются.
- **Интерактивные цели.** Жест, начатый на кнопке, ссылке, поле ввода или
  `contenteditable`, не перехватывается: нативные контролы продолжают работать
  штатно.

## `touch-action` и стилизация

Директива не рендерит DOM и не владеет стилями: CSS-переменных, `customClass` и
`ng-template` у неё нет. Для touch потребитель обязан поставить
`touch-action: none` на хост-элемент. Без этого браузер заберёт вертикальный
жест под прокрутку страницы, и `pointercancel` сбросит жест без выхода.

```scss
.player {
  touch-action: none;
}
```

`touch-action` — часть контракта, как `tabindex` у клавиатурной директивы.
Директива не выставляет его сама, чтобы не менять поведение прокрутки у
элемента, который потребитель использует не только как плеер.

## Доступность

- Директива не управляет фокусом, не добавляет `tabindex`, `role` и
  ARIA-атрибуты. Свайп — не единственный способ управления: рядом с плеером
  нужны доступные с клавиатуры и для скринридера кнопки и ползунки.
- Жест не является заменой `aria-label` или текстовой подсказки. Если жест
  важен для сценария, подскажите его в интерфейсе и в доступном описании.
- На интерактивных элементах жест игнорируется, поэтому кнопки, ссылки, поля
  ввода и редактируемые области внутри контейнера продолжают работать.

## SSR

Директива не использует `window`, `document` и медиа-API. На сервере нет
Pointer Events, поэтому обработчики не выполняются. Геометрия хоста и pointer
capture вызываются только внутри браузерных обработчиков; инициализация в
браузере не требуется.
